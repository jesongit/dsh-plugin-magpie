# Asset provenance

The only shipped identity artwork is the original Magpie small-size SVG silhouette from the local Magpie checkout at build/icon/magpie-small.svg. Its path data is preserved verbatim in src/client/icon.ts and reused by components and settings navigation; the React wrapper sets currentColor, requested dimensions and aria-hidden for adjacent labelled controls. Author: yetone, copyright 2026. Original MIT text is included in THIRD-PARTY-NOTICES and package.files includes that notice. No external image runtime request or upstream asset hosting dependency.

DSH visual aliases and SDK slot APIs are consumed from host peers; no DSH UI assets were copied. Other interface components and styles were authored for this connector. Browser verification images are synthetic fixture evidence, not shipping assets or real account screenshots. No generated imagery or model assets.
