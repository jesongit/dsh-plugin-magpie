# DSH Magpie connector surface

Mode: Operate. Extend existing DSH settings, navigation and composer; no visual-world replacement. User confirmed URL + key gate before opening the embedded management page, with friendly missing-configuration guidance. Code-first approved.

## Direction contract

THESIS: one small connector, not a second Magpie dashboard. Keep setup, connection evidence and original management UI distinct.

OWN-WORLD: inherit DSH alias background, border, label, business/error tokens, system font, native-sized controls and visible keyboard focus. No new fonts, imagery, gradients or marketing cards.

STORY: configure URL and key, explicitly allow creating a dedicated gateway key, connect, see discovered provider counts, then open management or refresh models. Desktop native webview issues and consumes one-time owner-RPC tickets, then posts login directly. Explain loading, unsupported desktop capability and host restrictions honestly; no automatic expiry/relogin in this phase.

FIRST VIEWPORT: compact heading and connection status; labelled URL and password fields, optional advanced gateway fields, one primary connect action; summary and secondary refresh/disconnect below. Main panel has a setup gate when missing; once configured it displays only the lazy managed native webview backend, with no connector title, status strip, actions or extra top padding. Settings remain in DSH settings; errors show an in-content retry state. Composer entry appears only for the current model's exact Magpie route; it opens a Codex-style anchored quota dialog for that supplier, never the full management panel or all suppliers. Three unified data treatments: percentage/count windows, balance/credits, and text/unlimited/unknown status. Shared-supplier and cache scope stated honestly.

FORM: fixed local extension, inherited DSH form/navigation composition; no concept seed required for precisely specified extension.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
